# Application Security Lab

Author: Samuel Cheung

## Overview

This repository contains practical notes, examples, and case studies related to Application Security.

Focus areas:

- OWASP Top 10
- Secure Coding
- SAST
- SCA
- DevSecOps
- Cloud Application Security

## OWASP Top 10 Topics Covered in V1

- A01 Broken Access Control
- A03 Injection
- A05 Security Misconfiguration
- A06 Vulnerable and Outdated Components
- A10 Server-Side Request Forgery

## Security Tools Covered

- Snyk
- Checkmarx
- SonarQube

## Case Studies

- Log4Shell
- SolarWinds
- MOVEit

## How To Use This Lab

Use this starter lab as a defensive reference for application security interviews, secure design discussions, developer awareness, and DevSecOps planning. The notes are intentionally concise and practical rather than production-ready policy.

## Disclaimer

This repository is for educational and defensive security purposes only.
