# Snyk Overview

## Description

Snyk is a developer-focused security platform that helps identify and remediate security issues earlier in the software delivery lifecycle.

## Key Areas

- Snyk Open Source: software composition analysis for open source dependencies.
- Snyk Code: static application security testing for source code.
- Snyk Container: container image vulnerability scanning.
- Snyk IaC: Infrastructure as Code security review.

## Where Snyk Fits in CI/CD

Snyk can be used in source control, developer workflows, build pipelines, container pipelines, and release gates. It helps teams find dependency, code, container, and IaC issues before production deployment.

## How It Helps Developers

- Highlights vulnerable dependencies and recommended upgrade paths.
- Provides earlier visibility before security review becomes a late project blocker.
- Supports DevSecOps workflows by integrating into developer tools and CI/CD.
- Helps prioritise issues based on severity, exploitability, and fix options.

## Difference From Other Tools

Snyk is especially strong in developer-friendly dependency security, SCA workflows, and actionable remediation guidance. It can complement enterprise SAST and code quality platforms.
